## Command Details

### Command 1

- **Command:** `docker --version`
- **Summary:** Prints the installed Docker client and server version. Used to confirm Docker is available before running containers.

### Command 2

- **Command:** `docker run hello-world`
- **Summary:** Runs the official `hello-world` image in a new container. Verifies that Docker can pull and run images and that the daemon is working.

### Command 3

- **Command:** `export $(cat .env | grep -v '^#' | xargs)`
- **Summary:** Loads environment variables from `.env` into the current shell. Skips comment lines (starting with `#`) and exports each `KEY=value` line so later commands can use them (e.g., build args and runtime env).

### Command 4

- **Command:** `docker build --build-arg NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY="$NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY" -t consultation-app .`
- **Summary:** Builds a Docker image from the current directory (`.`), passing the Clerk publishable key as a build argument for the Next.js app, and tags the image as `consultation-app` (default tag `latest`).

### Command 5

- **Command:** `docker run -p 8000:8000 -e CLERK_SECRET_KEY="$CLERK_SECRET_KEY" -e CLERK_JWKS_URL="$CLERK_JWKS_URL" -e OPENAI_API_KEY="$OPENAI_API_KEY" consultation-app`
- **Summary:** Runs the `consultation-app` image, mapping host port 8000 to container port 8000 and injecting Clerk and OpenAI credentials from the shell environment so the app can authenticate and call APIs.

### Command 6

- **Command:** `aws configure`
- **Summary:** Interactive setup for the AWS CLI. Prompts for access key, secret key, default region, and output format so subsequent `aws` and ECR commands are authenticated.

### Command 7

- **Command:** `dos2unix .env`
- **Summary:** Converts `.env` from Windows (CRLF) to Unix (LF) line endings. Prevents issues when the file is read by Unix tools or inside Linux containers.

### Command 8

- **Command:** `aws ecr get-login-password --region $DEFAULT_AWS_REGION | docker login --username AWS --password-stdin $AWS_ACCOUNT_ID.dkr.ecr.$DEFAULT_AWS_REGION.amazonaws.com`
- **Summary:** Logs the local Docker daemon into the AWS ECR registry for the given region and account. Uses the AWS CLI to obtain a short-lived password and pipes it to `docker login` so you can push/pull images to that ECR repository.

### Command 9

- **Command:** `docker build --platform linux/amd64 --build-arg NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY="$NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY" -t consultation-app .`
- **Summary:** Rebuilds the image for `linux/amd64` (e.g., for EC2 or ECS). Same build arg as before; the platform flag ensures the image runs on typical AWS Linux x86_64 hosts.

### Command 10

- **Command:** `docker tag consultation-app:latest $AWS_ACCOUNT_ID.dkr.ecr.$DEFAULT_AWS_REGION.amazonaws.com/consultation-app:latest`
- **Summary:** Tags the local `consultation-app:latest` image with the full ECR repository URI so Docker knows where to push it in the next step.

### Command 11

- **Command:** `docker push $AWS_ACCOUNT_ID.dkr.ecr.$DEFAULT_AWS_REGION.amazonaws.com/consultation-app:latest`
- **Summary:** Pushes the tagged image to the ECR repository. After this, the image is available in AWS for deployment (e.g., ECS, Lambda, or EC2).
